# Инструкции агенту

## Правки файлов — точечные, а не переписывание

Always use strict line-level diffs or small SEARCH/REPLACE blocks.
NEVER rewrite the whole class or file if the change is local. Be concise.

Практически это значит:

- меняешь одну функцию — правь эту функцию, а не выводи файл целиком;
- добавляешь зависимость — вставляй строку, а не перепечатывай весь блок;
- перед правкой прочитай нужный фрагмент, а не файл от начала до конца;
- в ответе показывай только изменённые места, а не итоговое содержимое.

Причина не только в токенах. При перепечатывании файла модель теряет детали:
в этом проекте так уже пропадали обёртка темы, цвета кнопок и префикс
`lifecycle-` у имён артефактов — файл оставался синтаксически верным, а
поведение ломалось.

Исключения, когда файл выводится целиком: создание нового файла, и правка,
затрагивающая больше половины содержимого.

## Что это НЕ отменяет

Кодогенерация движка (`.agent/run-agent.py`) работает иначе: её формат ответа —
`### FILE: путь` с полным содержимым файла, и по-другому парсер не умеет.
Правило выше на неё не распространяется.
