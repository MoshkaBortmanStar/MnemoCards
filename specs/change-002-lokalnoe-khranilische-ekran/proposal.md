# Proposal: Локальное хранилище и список колод

> **Change ID:** `add-offline-storage`
> **Дата:** 2026-09-16
> **Статус:** draft

Вводится локальная БД (Room) колод и стартовый экран со списком колод.

## Why

Данные сейчас захардкожены и теряются между запусками. Пользователю нужно хранить слова локально и выбирать колоду для тренировки.

## What Changes

- Колоды и карточки хранятся локально, переживают перезапуск.
- При первом запуске создаётся базовая колода из пяти слов.
- Стартовый экран — список колод: название, число карточек.
- Тап открывает тренировку колоды; «назад» — к списку.
- Сессия `cards.review` читает карточки из БД.
- Создание/редактирование колод, сеть — вне скоупа.

## New Capabilities

- `offline.storage` (v1): локальная БД — источник данных, полная работа офлайн.
