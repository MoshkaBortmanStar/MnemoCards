# Proposal: Экран тренировки карточек

> **Change ID:** `add-review-screen`
> **Дата:** 2026-09-16
> **Статус:** draft

Экран сессии повторения: слово на лицевой стороне, переворот по тапу, оценка ответа, переход к следующей карточке. Ядро продукта — учить слова — становится доступным пользователю.

## Why

Приложение пока не позволяет учить слова: основной пользовательский сценарий отсутствует. Тренировка закрывает ключевую ценность MnemoCards — повторение пар «слово–перевод» с самооценкой.

## What Changes

- Новый Compose-экран: лицевая сторона, переворот по тапу, кнопки оценки — Забыл, Трудно, Хорошо, Легко.
- После оценки — следующая карточка; когда колода закончилась — экран «на сегодня всё».
- Пять карточек захардкожены в коде; языковая пара произвольная.
- Без хранилища, сети и SRS-планирования.

## New Capabilities

- `cards.review` — сессия повторения с оценкой ответа; первая реализация на статических данных.
