# Proposal: Фоновая синхронизация колод с сервером

> **Change ID:** `add-background-sync`
> **Дата:** 2026-09-16
> **Статус:** draft

Изменения колод и карточек уходят на сервер, серверные — приходят обратно; офлайн-работа приложения сохраняется полностью.

## Why

Сейчас данные живут только на устройстве: потеря телефона стирает весь прогресс. Выученные слова должны сохраняться, колоды — быть доступными с нескольких устройств, без ущерба offline-first.

## What Changes

- Реализована capability `sync.background`: фоновый REST-обмен по контрактам specs/API.md и openapi.yaml.
- Запуск при открытии приложения и кнопкой на экране настроек; там же статус и ошибки.
- Прозрачное обновление токена; при отказе — состояние «требуется вход», данные не теряются.

## New Capabilities

- `sync.background` — фоновая синхронизация колод и карточек с сервером, не мешающая локальной работе.
